# Experiment 1 — Git Basics

## Aim
Practice creating a repository, staging changes, committing them, and checking the history.

## Commands
```bash
git --version
git init
git status
git add README.md
git commit -m "Add project README"
git log --oneline
```

## Key concepts
- **Working tree:** files currently being edited.
- **Staging area:** changes selected for the next commit.
- **Commit:** a saved snapshot of staged changes.
- **Repository:** project files plus their version history.
