# Experiment 6 — GitHub Actions

## Aim
Run an automated workflow when code is pushed or a pull request is opened.

This repository includes a starter workflow at `.github/workflows/ci.yml`. It checks out the repository and runs a small shell check.

## How to test
1. Push this repository to GitHub.
2. Open the **Actions** tab.
3. Select the workflow run triggered by your push.
4. Inspect the job logs and record the result.
