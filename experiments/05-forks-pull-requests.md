# Experiment 5 — Forks and Pull Requests

## Aim
Practice contributing changes through a fork and pull request.

## Workflow
1. Open a project on GitHub and fork it (when you have permission to contribute).
2. Clone your fork.
3. Create a feature branch.
4. Make a small, meaningful change.
5. Commit and push the branch.
6. Open a pull request from your branch.
7. Review feedback and update the branch if required.

## Commands
```bash
git clone https://github.com/YOUR-USERNAME/PROJECT.git
cd PROJECT
git switch -c docs/improve-readme
git add README.md
git commit -m "Improve README documentation"
git push -u origin docs/improve-readme
```
