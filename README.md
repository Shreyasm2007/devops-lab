# DevOps Laboratory — Git & GitHub

A learning repository for practicing Git fundamentals and collaborative development workflows.

## Experiments
1. Git basics and repository setup
2. Remote repositories: push, pull, fetch, clone
3. Branching and merging
4. Merge conflicts and rebasing
5. Forks, pull requests, and collaboration
6. GitHub Actions basics

> This repository is a starter template. Add your own screenshots, command outputs, and observations after running each experiment.

## Requirements
- Git
- A GitHub account
- A terminal (Git Bash, PowerShell, or a Linux/macOS shell)

## Quick start
```bash
git clone https://github.com/YOUR-USERNAME/devops-lab.git
cd devops-lab
git status
```

## Suggested workflow
1. Create a feature branch.
2. Make a small change.
3. Commit it with a descriptive message.
4. Merge it into `main` (or open a pull request on GitHub).

## Repository structure
- `experiments/` — short experiment guides
- `scripts/` — small helper scripts
- `.github/workflows/` — GitHub Actions workflow examples
